# [<img src="https://s3.vpndetection.io/vpndetection-public/brand/mark.svg" alt="VPNDetection" height="28"/>](https://vpndetection.io/) Homebrew tap

The Homebrew tap for [VPNDetection](https://vpndetection.io)'s official command line interface.

```bash
brew trust vpndetection-io/tap
brew tap vpndetection-io/tap
brew install vpndetection
```

`brew upgrade` keeps it current. Homebrew won't load a formula from a third-party tap until you trust it, and without the first line it fails with `invalid syntax in tap!`. `brew trust` arrived in Homebrew 7, so run `brew update` first if it comes back as an unknown command.

The formula in `Formula/` is generated by the [CLI repository](https://github.com/vpndetection-io/cli)'s release workflow, so don't edit it by hand. Open issues against that repository rather than this one.
