# [<img src="https://s3.vpndetection.io/vpndetection-public/brand/mark.svg" alt="VPNDetection" width="24"/>](https://vpndetection.io/) Homebrew tap

The Homebrew tap for [VPNDetection](https://vpndetection.io)'s official command line interface.

```bash
brew tap vpndetection-io/tap
brew install vpndetection
```

`brew upgrade` keeps it current.

The formula in `Formula/` is generated by the [CLI repository](https://github.com/vpndetection-io/cli)'s
release workflow, so don't edit it by hand. Open issues against that repository rather than this one.
